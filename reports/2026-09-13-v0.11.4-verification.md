  delegates (no SQL in handler). Unknown → `RESOURCE_NOT_FOUND`; ambiguous →

## Code Review notes (commander)

- #191: exact-name duplicates now fail as ambiguous instead of first-match
  (stricter than `export --focus`, correct for edges lookup). Suffix match is
  bare `ends_with` (same as focus; `a.rs` also matches `ba.rs`) — by design,
  documented in arg help.
- #192: every `use crate::X` now also probes `src/X/mod.rs`; a repo with both
  `src/X.rs` and `src/X/mod.rs` yields two edges (rare, arguably correct).
  Multiline and `pub(crate/super) use` now parse — `scan` edge counts on such
  repos increase vs 0.11.3, expected.
- Stray observation (pre-existing, out of scope): none blocking; no new
  public incompatibilities — JSON envelopes, error codes, and exit codes
  unchanged except the new documented `VALIDATION_FAILED`/exit-8 ambiguity
  path for `graph edges`.
